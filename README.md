# Kubernaut for OpenShift Ops

**Live Presentation:** [https://rrbanda.github.io/knaut/](https://rrbanda.github.io/knaut/)

## Overview

This repository contains a presentation deck introducing **Kubernaut** -- an AI-powered intelligent remediation platform for OpenShift/Kubernetes operations.

## Viewing the Presentation

- **Live:** Visit [https://rrbanda.github.io/knaut/](https://rrbanda.github.io/knaut/)
- **Navigation:** Use arrow keys or swipe to move between slides
- **Speaker Notes:** Press `S` to open the speaker notes window (recommended for presenters)
- **Full Screen:** Press `F` for full-screen presentation mode
- **Overview:** Press `O` (or `Esc`) for slide overview
